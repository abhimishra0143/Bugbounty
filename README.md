# Bugbounty

Authorized bug bounty — methodology, class notes, original writeups, recon.
Everything here is built from FIRST-HAND work, not copy-paste.

## How to use this repo (class method)
1. `methodology/`  — one file per bug class. Read BEFORE hunting.
2. `checklists/`   — per-engagement hunting checklist (copy, tick off).
3. `mindmaps/`     — the THINKING behind each find (approach, not just steps).
4. `lab/`          — local practice (PortSwigger, DVWA, self-built).
5. `reports/`      — your own writeups, written to learn + for disclosure.
6. `targets/`      — disclose.io mirrored program list, tracked per hunt.
7. `recon/`        — raw recon output per target (subdomains, hosts, etc).

## Rule
No hunting without explicit scope (HackerOne/Bugcrowd/Intigriti/self-hosted VRP).
Think first, tool second. Document the WHY, not just the HOW.
